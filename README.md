# Flight Search MCP

This project scrapes flight data from various websites.

## Usage

### Expedia Scraper

To run the scraper for Expedia, execute the following command:

```bash
python scrapper/expedia/expedia_scrap.py
```

This will scrape the data from the website.

For data extraction from the scraped content using Beautiful Soup, run:

```bash
python scrapper/expedia/data_extraction.py
```
